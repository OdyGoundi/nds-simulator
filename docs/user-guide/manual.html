NLDS Simulator Manual

Quick, practical guide to build systems, choose solvers, and generate phase portraits, Lyapunov exponents, and sweeps.

Quick Start

  1. 1
    Choose a system (sidebar). Built-in: Lorenz, Rossler, Henon-Heiles. Or create a Custom system with your own variables and equations.
  2. 2
    Pick a solver. Use RK45/DOP853 for accuracy or RK4 for speed. Symplectic Forest-Ruth is for Hamiltonian systems only.
  3. 3
    Set integration (Tab 1): t0, tf, dt, plus parameters. Adjust axis selection for 2D/3D phase plots.
  4. 4
    Compute Lyapunov (Tab 1): set QR interval and transient fraction, then click Compute.
  5. 5
    Analyze sweeps (Tab 3): select sweep parameter, Poincare section, method, and mode (reset vs continuation).
  6. 6
    Export (Tab 4): download trajectories, sweeps, and Lyapunov results.

Custom System

Custom Jacobian (Lyapunov)

  • Enable Auto-compute Jacobian (symbolic).
  • Toggle Use analytic Jacobian to speed up Lyapunov.

Solver Guide

SolverBest forNotes
RK45General useAdaptive step, reliable default
DOP853Non-stiff, smooth systemsHigh order, accurate
RK4Speed / sweepsFixed dt, Numba accelerated
Symplectic Forest-RuthHamiltonian systemsState is [q..., p...], even dimension; Numba accelerated when available
Tip: For sweeps, RK4 with a plane section is the fastest path.

Phase Portrait (Tab 1)

  • Set t0, tf, dt and system parameters.
  • Choose 2D or 3D axes.
  • Use Transient cut to remove early dynamics.

Lyapunov (Tab 1)

  • Set QR interval (time).
  • Set Transient fraction for Lyapunov accumulation.
  • Click Compute Lyapunov exponents.

Time Series (Tab 2)

  • Plot any variable vs time.
  • Compare components and check stability.

Poincare Section (Tab 3)

  • Plane section: choose section variable and value.
  • Equation section: enter an expression (overrides plane).
  • Method: crossing or slab (tolerance band).

Parameter Sweeps (Tab 3)

Bifurcation Sweep

  • Select sweep parameter, range, and step.
  • Choose method and direction.
  • Mode: reset ICs or continuation (warm start).

Lyapunov Sweep

  • Uses same parameter range.
  • Set QR interval and transient fraction.
  • Parallel only in independent mode.

Export (Tab 4)

  • Download trajectories (CSV).
  • Download sweep results (CSV).
  • Export Lyapunov results and configs.

Troubleshooting

  • Slow Reduce max steps or increase dt carefully.
  • No section hits Adjust section value or direction.
  • Noisy Lyapunov Increase tf or reduce dt.
