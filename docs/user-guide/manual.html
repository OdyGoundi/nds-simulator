dynaSim Manual

Quick guide to defining dynamical systems, choosing integrators, phase portraits, time series, Lyapunov exponents, and parametric sweeps with Poincare sections.

Version: 3.1.2 Last updated: February 2026

Quick Start

  1. 1
    Choose a system from the sidebar (built-in or Custom nD).
  2. 2
    Choose an integrator (RK45/DOP853 for high trajectory accuracy, RK4 for speed, symplectic only for Hamiltonian).
  3. 3
    Set integration: initial time, final time, time step, initial values and system parameters.
  4. 4
    Phase portrait (Tab 1) and time series (Tab 2). Use Transient cut to remove early steps as transient regime.
  5. 5
    Lyapunov: set transient and QR interval (how often we orthonormalize) in Tab 1 and click Compute Lyapunov exponents.
  6. 6
    Sweeps / Poincare (Tab 3): sweep parameter, section, method, mode (reset vs continuation).
  7. 7
    Export (Tab 4): trajectories, sweep results, Lyapunov and configs/settings.
Tip: Start with small final time and a “moderate” time step for a quick sanity check. Then increase duration/resolution for stable results.

Custom System (Custom nD)

Define variables, equations and parameters from the sidebar. Expressions use Python/SymPy syntax. For non-autonomous systems you can use the time variable t.

Variables

y1
y2
y3

Equations (Lorenz example)

sigma * (y2 - y1)
y1 * (rho - y3) - y2
y1 * y2 - beta * y3

Parameters

sigma=10
rho=28
beta=2.6666667

Jacobian for Lyapunov

  • Enable Auto-compute Jacobian (symbolic) where available.
  • Enable Use analytic Jacobian to speed up Lyapunov exponent computation.

Numerical Integration Guide

SolverBest forNotes
RK45General useAdaptive step, reliable default for baseline runs.
DOP853Non-stiff, smooth systemsHigh order, usually better accuracy for demanding trajectories.
RK4 (fixed-step)Speed / sweepsFixed dt, predictable cost; recommended when you need many runs.
Symplectic (Forest–Ruth / Verlet)Hamiltonian systemsState [q..., p...], even dimension; better long-term energy behavior.

How do I choose dt / tolerances?

  • Fixed-step (RK4): decrease the time step until key features stabilize (attractor geometry, Poincare points).
  • Adaptive (RK45/DOP853): start with “medium” rtol/atol values and tighten only if needed (drift/artefacts).
  • Chaos note: in chaotic systems trajectories diverge pointwise; judge with geometry/statistics/observables.
Lyapunov (performance rule): For Lyapunov exponents, prefer a fixed-step solver strictly (e.g. RK4), for performance (Numba).

Tab 1 — Phase Portrait

  • Set initial time, final time, time step, parameters and initial values.
  • Choose 2D or 3D axes (for nD systems you see projections).
  • Use Transient cut to remove transients.

Lyapunov (Tab 1 / corresponding panel)

  • Set Transient (fraction/time) and QR interval.
  • Click Compute Lyapunov exponents.
Practical: A smaller QR interval (more frequent re-orthonormalization) usually helps stability. Stable estimates require a sufficiently large final time after the transient.

Tab 2 — Time Series

  • Plot any variable versus time.
  • Useful for checking stability, scales, transients and selecting a suitable final time.

Tab 3 — Poincare Section & Parametric Sweeps

Poincare Section

  • Plane section: select section variable and value.
  • Equation section: enter an expression (overrides plane section).
  • Method: crossing or slab (tolerance band).

Parameter sweeps

  • Select sweep parameter, range and step.
  • Mode: bifucartion(reset ICs) or continuation (warm start).
  • For faster bifurcation diagrams use RK4 and a suitable number of Poincare hits / early stop where available.

Study workflow (chaotic + parametric behavior)

  • After setting up equations, choose integration settings that allow sufficient system evolution.
  • For Lyapunov at fixed parameter values, use a relatively long time horizon. Example: with time step 0.01, final time 10000 is often safe.
  • For parametric study (bifurcation diagrams and Lyapunov vs parameter), start with a few values and increase resolution gradually.
  • Based on time series, choose a suitable section equation for the Poincare cut to obtain valid crossing values. Use consistent settings when generating the Lyapunov diagram.
  • Balance quality vs runtime by adjusting final time until behavior is captured without excessive cost.
  • If you are not using warm start (where each run starts from the final state of the previous), parallelize with the workers slider and reset ICs per parameter to reduce total time.
Tip: If no sections are found, change section value or direction, increase tf (sweep), or try slab with a slightly larger tolerance.

Tab 4 — Export & Reproducibility

  • Download trajectories (CSV).
  • Download sweep results (CSV).
  • Export Lyapunov results and full configs/settings.

For use in the notebooks

  • Use Save/Export from the Export tab.
  • Load the configs in the corresponding notebook (A or B), depending on the workflow.

Troubleshooting

  • Slow Reduce final time, carefully increase time step (i.e., fewer steps), or reduce max hits.
  • No section hits Change section value/direction or try slab.
  • Noisy Increase final time, reduce time step, or use analytic Jacobian.
